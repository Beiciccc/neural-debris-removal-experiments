# Neural Debris Removal Experiments

Public experiment log and generated submission artifacts for the Kaggle competition [Neural Debris Removal in Streak Detection Models](https://www.kaggle.com/competitions/neural-debris-removal-in-streak-detection-models).

## Repository Scope

This repository is intentionally limited to project introduction, experiment records, public leaderboard snapshots, candidate statistics, and generated submission CSV files. It excludes raw competition data, model weights, credentials, local logs, and run-control files.

## Current Public Result Snapshot

Best public score recorded in this snapshot: **244.0303** from `sub111_nomannic_sub106_img1409_conf04625.csv`. Lower is better.

## Contents

- `records/experiment_records.md`: human-readable experiment summary.
- `records/submission_history.csv`: sanitized public submission history.
- `records/candidate_summary.csv`: lightweight statistics for generated candidates.
- `records/leaderboard_public_snapshot.csv`: public leaderboard snapshot with team identifiers removed where possible.
- `submissions/`: generated submission CSV artifacts.
- `data/README.md`: data access note; raw competition data is not redistributed here.

## Reproducibility Notes

The records here document submitted artifacts and public outcomes. Raw data must be obtained directly from Kaggle under the competition terms.
